# Six of Pentacles · 星币六

> *星币六，象征财富、资源与价值的流动。*
> 
> *逆位，代表**资源失衡、过度给予与无序支出；***
> 
> *正位，代表**财富平衡、收获回馈与良性流动。***
> 
> *逆位到正位的翻转，是财富失衡到平衡的转变。*
> 
> ***愿每一份克制，都通向你的心愿。***
> 
> 


## 1. 产品简介

**Six of Pentacles · 星币六** 是一款面向个人消费决策的移动端应用。

《2025 Z世代情绪消费报告》\(Soul App联合上海市青少年研究中心发布\)显示，**近6成年轻人愿意为情绪价值买单**,这一比例较2024年增长16\.2%；**年轻人情绪消费的月均支出达到949元，**其中2成年轻人是情绪消费的“日活型用户”，然而，**情绪消费的支出为年轻人带来的究竟是愉快的情绪还是越堆越长的花呗账单？**调查显示，**34%的消费者曾因冲动消费而经历财务压力**\(来源:Fortunly《15\+ Impulse Buying Statistics for 2026》\)，说明这不只是“买了不合适的东西”这么简单，而是会实际影响个人财务健康；**冲动消费占到全部电商消费金额的近40%**\(来源:gitnux《150\+ Impulse Buying Stats》\)，体量上已经不是消费行为里的“边角料”。

**Six of Pentacles · 星币六 **想做的事很简单：在“想买”和“值得买”之间，多留一点停顿的空间。

大多数记账工具关心的是“你花了多少钱”，而星币六关心的是“这次冲动，值不值得让步”。它不会替你做决定，只会在你要下单前，把一件事摆在你面前——你已经拥有的东西里，有没有和这次想买的东西很像的?那些东西后来怎么样了?

用户可以在星币六里记录自己的闲置/持有物品、维护一份心愿单，并通过 AI 完成商品识别、消费评估、心愿资金记录。产品的核心不是“预测”或“建议”，而是**把“你已经拥有什么”和“你正要花钱买什么”放在同一个对话里**，让每一次消费冲动，都有机会被看见、被多想一秒。


## 2. 核心理念

- **不做预测，只做事实陈述**。星币六的 AI 不会告诉你“该不该买”，它只会告诉你“你过去买过类似的东西，后来怎么样了”——决定权始终在你手上。

- **忍住的每一分钱，都有去处**。当你在 AI 的陪伴下选择“这次不买了”，这笔钱不会消失在流水账里，而是直接流向你正在攒的一个具体心愿——一张演唱会门票，一次旅行，或任何你真正想要的东西。

- **对话，而不是报表**。星币六不是一个记账本，是一个可以随手发一张照片、随口聊两句“我是不是又想乱买东西了”的对话空间。


## 3. 功能详细描述

### 3\.1 心愿单与资金规划

用户可以创建心愿单，把真正想要的目标保存下来——一次旅行、一张门票、一件很想要但暂时舍不得买的东西。

星币六会把用户**每一次“忍住没买”省下的钱**，记入对应心愿的资金进度。心愿达成后，系统会生成一张心愿达成卡片，支持保存到相册或分享，把“攒钱的过程”变成一件值得被记录、被看见的小事，而不只是一个默默完成的任务。

### 3\.2 AI 消费评估\(核心对话能力\)

这是星币六里用户交互最频繁、也是最核心差异化的部分。

**灵感来自一个很日常的场景**：纠结要不要买一件东西时，大多数人会先去问朋友“你觉得我该买吗”。星币六把这个场景搬进了产品里——用户可以像跟朋友聊天一样，随手把商品描述、链接，或一张照片发给 Agent，展开一段对话。

这段对话不是一次性的问答，Agent 会结合两类记忆：

- **用户的资产库**：过去买过什么、后来是常用还是闲置了

- **和用户的聊天记录**：之前纠结过什么、最后怎么选的

基于这两类记忆，当用户问“这个到底要不要买”时，Agent 给出的是**有依据的事实**，而不是空泛的判断——比如“你上个月纠结过一件很像的东西，当时也是这么犹豫的”。这些事实是为“帮用户对冲冲动消费”这个目的服务而挑选的，天然带一点劝退的倾向，但 Agent 不会说“你不该买“这种指令式的话，决定权始终交还给用户。

对话的最后，用户面对三个选择：**买 / 冷静24小时 / 不买**。

- 选择「不买」，这笔钱立刻计入用户指定的心愿

- 选择「冷静24小时」，系统会在24小时后提醒用户回来确认；**如果用户届时仍未做出选择，系统默认视为“没买”，金额同样计入心愿**——用一个温和的默认机制，把“拖延决定”也转化成一次小小的克制

- 选择「买」，如实记录，不评判，对话继续

这套“对话 \+ 量化激励”的设计，让“理性消费”这件通常有点辛苦、需要意志力的事，变成了一个有反馈、有小小成就感、甚至可以拿出来晒一晒的过程——市面上目前几乎没有专门为“劝住冲动消费”这一个场景服务的 Agent，大多数同类产品做的是记账提醒或预算超支警告，而不是这种“像朋友一样聊两句”的陪伴式对话。

### 3\.3 个人资产管理\(支撑数据\)

用户可以添加并管理自己的物品，包括名称、品牌、型号、分类、成色、购买时间、购买价格和照片等信息。

这部分**不是产品的主战场，而是让 Agent 对话更有依据的地基**——星币六之所以能在对话里说出“你过去买过类似的东西”这种有说服力的话，靠的就是这份资产记录。资产页面会汇总当前物品的持有/闲置/已卖出状态，帮用户随时看清“我已经拥有了什么”。

### 3\.4 图片识别与物品录入

支持通过相机或相册上传物品照片，系统会辅助识别物品信息，降低手动记录的门槛。用户也可以选择跳过拍照，直接手动填写。

### 3\.5 每日二手市场参考价\(资产页辅助能力\)

资产页里的每件物品，会展示一个基于每日二手市场数据得出的参考价格。这部分呈现的是客观的市场参考信息，帮用户对“我这东西现在值多少钱”有一个大致概念，**不作为核心卖点**，更多是资产页的辅助信息，增加“这份资产记录是活的、会更新的”这种真实感。

对已录入的资产，系统可提供二手市场的参考估价，帮助用户对“我这东西现在值多少钱”有一个大致的概念。这部分呈现的是客观参考数据，不作为购买或卖出的决策依据。

## 4. 配置 Supabase 与管理员

当前开发资源由 Vercel Marketplace 的 Supabase 集成托管。App 没有注册、登录或退出页面，启动时使用本机环境变量中的固定管理员自动登录。

首次配置：

macOS / Linux：

```bash
vercel link
vercel integration add supabase
vercel env pull .env.local --environment=development --yes

source .env.local
npx supabase db push --db-url "$POSTGRES_URL_NON_POOLING" --include-all
```

Windows PowerShell：

```powershell
vercel link
vercel integration add supabase
vercel env pull .env.local --environment=development --yes

$worthEnv = Get-Content .env.local | ConvertFrom-StringData
$env:POSTGRES_URL_NON_POOLING = $worthEnv.POSTGRES_URL_NON_POOLING.Trim('"')
npx supabase db push --db-url $env:POSTGRES_URL_NON_POOLING --include-all
```

固定管理员凭据保存在 Vercel 环境变量 `EXPO_PUBLIC_ADMIN_EMAIL` 和 `EXPO_PUBLIC_ADMIN_PASSWORD`。这是仅供个人局域网 MVP 使用的临时方案；公开发布前必须更换正式认证。

## 5. 配置 API

服务端需要 Python 3.11–3.13；`rembg` 当前不支持 Python 3.10 及以下或 3.14 及以上。

macOS / Linux：

```bash
cd server
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements-local.txt
cd ..
vercel env pull server/.env --environment=development --yes
```

Windows PowerShell：

```powershell
Set-Location server
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-local.txt
Set-Location ..
vercel env pull server/.env --environment=development --yes
```

资产和待购商品的图片识别继续通过 Vercel AI Gateway 调用 OpenAI Responses API；商品分类、市场候选文本筛选和评估对话优先调用 DeepSeek，未配置 DeepSeek 时回退到原有通道：

```dotenv
AI_GATEWAY_API_KEY=
OPENAI_MODEL=openai/gpt-5.4
DEEPSEEK_API_KEY=
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-v4-flash
SUPABASE_URL=
SUPABASE_ANON_KEY=
XIANYU_COOKIE=
```

`XIANYU_COOKIE` 只存在于服务端或 Cloudflare Secret。可使用参考项目 `https://github.com/ylw5/XianYuApis` 的 `qrcode_login()` 完成运营侧扫码登录，再把完整 Cookie 写入服务端机密环境变量。App 中没有数据源连接或扫码入口。

启动 API：

macOS / Linux：

```bash
cd server
.venv/bin/python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Windows PowerShell：

```powershell
Set-Location server
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

## 6. 配置每日市场估值

Cloudflare Worker 每天 02:00（Asia/Shanghai）为“使用中”“闲置”和“出售中”的资产创建行情任务。已售资产不再刷新；失败任务不会覆盖最近一次成功估值。

首次部署：

```bash
npx supabase db push

cd cloudflare
npx wrangler@latest secret put SUPABASE_SERVICE_ROLE_KEY
npx wrangler@latest secret put XIANYU_COOKIE
npx wrangler@latest secret put AI_GATEWAY_API_KEY
uv run pywrangler deploy
```

密钥只输入到 Wrangler Secret 提示中，不写入 `.env`、配置文件或日志。

本地验证：

```bash
cd cloudflare
uv run pytest -q
uv run pywrangler deploy --dry-run
```

## 7. 启动 App

先在 `mobile/` 下创建 `.env.local`：

macOS / Linux：

```bash
cd mobile
cp .env.example .env.local
```

Windows PowerShell：

```powershell
Set-Location mobile
Copy-Item .env.example .env.local
```

填写以下配置：

```dotenv
EXPO_PUBLIC_SUPABASE_URL=
EXPO_PUBLIC_SUPABASE_ANON_KEY=
EXPO_PUBLIC_ADMIN_EMAIL=
EXPO_PUBLIC_ADMIN_PASSWORD=
```

前两个值分别对应根目录 `.env.local` 中的 `NEXT_PUBLIC_SUPABASE_URL` 和 `NEXT_PUBLIC_SUPABASE_ANON_KEY`。真机开发时建议把 `EXPO_PUBLIC_API_URL` 显式设置为开发机局域网地址，例如 `http://192.168.1.10:8000`；未设置时应用会依次尝试从 Expo Config、Expo Go 和 Web 开发地址推导。

然后在 `mobile/` 目录启动：

```bash
npm install
npm start
```

手机必须和开发机处于同一 Wi-Fi。
